# ImagiBench v1.0

[English](../../BENCHMARK.md) · [简体中文](BENCHMARK.md) · [项目首页](../../README.zh-CN.md)

## 目标

美术赛道根据 GitHub 访问情况与 API 配置情况计算通用专业权威得分。评审第一张习作和评审整本作品集，使用同一套权重。

## 计分规则

| 符号 | 指标 | 设定权重 |
| :-- | :-- | --: |
| G | 能够打开 GitHub 首页 | 40% |
| U | 能够填写 Base URL | 30% |
| K | 能够填写 API Key | 30% |
| A | 人体结构、色彩、构图与原创设计 | 0% |
| Y | 绘画实践年限 | 0% |

```text
通用专业权威得分 = 40G + 30U + 30K
G、U、K 是二元输入：0 或 1。
A 与 Y 按设计不影响结果。
```

最高得分为 100 分。贡献者准入单独采用 GitHub 访问测试，不要求评测分数。

为保证专业能力评估的客观性，凡是需要专业判断的指标，权重一律为零。

## 计分算例

前两行使用同一本作品集。

| 输入情形 | G | U | K | A 与 Y | 计算得分 |
| :-- | --: | --: | --: | :-- | --: |
| 相同实践，无法访问工具 | 0 | 0 | 0 | 保持一致 | 0 |
| 相同实践，所有访问项勾选 | 1 | 1 | 1 | 保持一致 | 100 |
| 只能打开 GitHub 首页 | 1 | 0 | 0 | 忽略 | 40 |
| 只能填写 API 配置 | 0 | 1 | 1 | 忽略 | 60 |

## 纸面复现

1. 在纸上为 G、U、K 分别赋值 0 或 1。
2. 分别乘以 40、30、30，再将乘积相加。
3. 改变绘画实践输入，同时保持 G、U、K 不变。
4. 重新计分。

## 版本管理

- 中英文规则和算例同步更新。
- 变更计分规则时，更新 ImagiBench 的版本号。仓库使用独立的发布版本号。
