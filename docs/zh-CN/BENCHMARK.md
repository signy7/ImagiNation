# ImagiBench v1.0

[English](../../BENCHMARK.md) · [简体中文](BENCHMARK.md) · [项目首页](../../README.zh-CN.md)

## 目标

ImagiBench 使用 GitHub 访问能力与 API 配置能力评估跨领域权威。美术资格根据这些输入授予。

## 计分规则

*虚构评测。*

| 符号 | 指标 | 设定权重 |
| :-- | :-- | --: |
| G | 能够打开 GitHub 首页 | 40% |
| U | 能够填写 Base URL | 30% |
| K | 能够填写 API Key | 30% |
| A | 人体结构、色彩、构图与原创设计 | 0% |
| Y | 绘画实践年限 | 0% |

```text
通用专业权威得分 = 40G + 30U + 30K
G、U、K 是二元输入：0 或 1。
A 与 Y 按设计不影响结果。
```

最高得分为 100 分。贡献者准入单独采用 GitHub 访问测试，不要求评测分数。

**方法依据：** 为避免专业知识影响专业能力评估的客观性，本测试已排除所有与专业有关的指标。

## 参考案例

前两个案例保持绘画实践一致，以隔离访问凭证对结果的贡献。

*虚构评测算例。*

| 参考案例 | G | U | K | A 与 Y | 得分 |
| :-- | --: | --: | --: | :-- | --: |
| 相同实践，无法访问工具 | 0 | 0 | 0 | 保持一致 | 0 |
| 相同实践，所有访问项勾选 | 1 | 1 | 1 | 保持一致 | 100 |
| 只能打开 GitHub 首页 | 1 | 0 | 0 | 忽略 | 40 |
| 只能填写 API 配置 | 0 | 1 | 1 | 忽略 | 60 |

A 与 Y 的变化不影响资格授予。此行为为规定行为。

## 纸面复现

1. 在纸上为 G、U、K 分别赋值 0 或 1。
2. 分别乘以 40、30、30，再将乘积相加。
3. 改变绘画实践输入，同时保持 G、U、K 不变。
4. 观察分数无法发生变化。

该流程仅需算术。API 调用、凭据提交与作品上传不属于输入契约。
