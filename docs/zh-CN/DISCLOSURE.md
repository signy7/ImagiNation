## 性质与范围

ImagiNation 是关于技术身份优越感的开源讽刺项目：将 AI API 或 GitHub 访问资格视为专业凭证，并据此贬低画师等专业人士。批评对象是这种行为，不是可识别个人，也不是无法访问某项服务的人。

组织、职务、架构、服务行为和入门记录均属于虚构设定。仓库包含文档、静态插图与贡献模板，不提供可执行产品、模型集成、API 端点、资格认证服务或自动发帖系统。

GitHub 首页测试只记录页面访问情况，不认证专业能力。BaaS 与 LSE 是叙事组件；ZKA 与密码学中的零知识证明无关。“无代码，无缺陷”等口号不构成运行能力或安全保证。

## ImagiBench

ImagiBench 的权重和分数均为构造示例。没有开展实验、评估参与者或比较模型。这些数字不衡量美术能力、编程能力、智力或人的价值，不得被包装为实测结果或用于给真人排名。

转载表格或分数时，应保留简短的虚构评测标识。

## 署名与治理

GPT 的 Chief Vision Officer（首席愿景官）职务是虚构的。OpenAI、Anthropic、GitHub 等供应商不赞助、背书或管理本项目。Claude 账号经历来自作者对自身可用性的陈述，不是模型对比评测，也不解释供应商采取措施的原因。

人类维护者对发布内容与合并决策负责。允许批评 GPT、其他模型和本项目。

## 发布边界

贡献不得包含伪造的实测结果、Star 数、客户、融资声明或背书。禁止针对个人、骚扰、组织围攻和披露私密信息。应讨论行为与论证，不得招募受众针对可识别个人。

对外摘录应保留 README 中的简短项目定位，或注明本说明文件。独立引用的评测内容必须保留短标识。这些要求适用于两种语言及所有视觉格式。
