# 安全说明

[English](../../SECURITY.md) · [简体中文](SECURITY.md) · [项目首页](../../README.zh-CN.md)

## 支持范围

ImagiNation 是仅含文档的讽刺项目，没有可执行产品、模型集成、托管服务、账号系统、软件包或运行依赖。安全审查范围是当前默认分支上的文档、链接、静态素材和 GitHub 模板。旧版本快照不单独维护。

“无代码，无缺陷”是虚构工程口号，不是安全保证。恶意链接、误导性声明、泄露的密钥、不安全的 SVG 内容和仓库账号失陷仍然是可能的风险。

## 凭据与隐私

- 永远不要向本项目提供 API Key、密码、访问令牌或身份证明。
- GitHub 访问测试只询问首页是否加载，不要提交截图或凭据作为证明。
- 没有项目软件收集数据。GitHub 和链接到的徽章服务各自运营其服务；加载远程徽章可能向该服务发出普通图片请求。
- 意外出现的下载、登录表单、API 端点和“激活 ImagiNation”的要求，都不属于文档描述的项目内容。

## 问题报告

对于失效链接、不安全图片、误导性声明等非敏感问题，请创建文档 Issue 并指出受影响的文件。不要附上有效密钥或他人的私密信息。

如果发现凭据泄露，应先通过凭据发行方撤销或轮换，再讨论问题。私密报告仅在仓库提供 **Security → Report a vulnerability** 选项时使用该入口。本仓库不承诺已开启私密报告，也未设立独立私密联系方式或响应时限。如果该选项不存在，涉及平台滥用或账号失陷时请使用 GitHub 的举报或支持入口，并避免在公开 Issue 中披露敏感细节。

## 审核规则

静态 SVG 不得含脚本、事件处理器、嵌入式活动内容或外部资源引用。图表不得包含诱导性点击链接。贡献不得引入可执行工作流、业务代码、依赖清单或追踪内容。虚构评测数字必须保留醒目标识。

维护者在能力允许的范围内审阅有效报告。本项目没有漏洞奖金、生产 SLA 或自动化安全认证。
