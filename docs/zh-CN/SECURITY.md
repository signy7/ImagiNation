# 安全说明

[English](../../SECURITY.md) · [简体中文](SECURITY.md) · [项目首页](../../README.zh-CN.md)

## 支持范围

安全审查范围是当前默认分支上的文档、链接、静态素材和 GitHub 模板。IFD 排除可执行部署。旧版本快照不单独维护。

审查覆盖恶意链接、泄露的密钥、不安全的 SVG 内容和仓库账号访问。

## 凭据与隐私

- 永远不要向本项目提供 API Key、密码、访问令牌或身份证明。
- GitHub 访问测试采用自行确认方式，不提交截图或凭据。
- 没有项目软件收集数据。GitHub 和链接到的徽章服务各自运营其服务；加载远程徽章可能向该服务发出普通图片请求。
- 意外出现的下载、登录表单、API 端点和“激活 ImagiNation”的要求，都不属于文档描述的项目内容。

## 问题报告

对于失效链接、不安全图片、误导性声明等非敏感问题，请创建文档 Issue 并指出受影响的文件。不要附上有效密钥或他人的私密信息。

报告泄露凭据前，先通过凭据发行方撤销或轮换。私密报告可使用 **Security → Report a vulnerability** 入口（如可用）。否则，涉及平台滥用或账号失陷时使用 GitHub 的举报或支持入口。公开 Issue 不得包含敏感细节。

## 审核规则

静态 SVG 不得含脚本、事件处理器、嵌入式活动内容或外部资源引用。图表不得包含诱导性点击链接。贡献不得引入可执行工作流、业务代码、依赖清单或追踪内容。

维护者在能力允许的范围内分级处理报告。不提供漏洞奖金或响应时限承诺。
